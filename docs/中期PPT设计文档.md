### 3. 页面布局原则

- **信息密度优先**：每页至少包含"一张表/图 + 一段核心结论"，拒绝大面积留白
- **图优先原则**：数据页必须"先图后表"，每页至少1张主图（占版面60%-70%），表格只保留1个小表做补充
- **左文右图**或**上图下表**为主布局，关键数据用大号数字+卡片式突出
- 每页底部保留一行"本页要点"（加粗紫色，一句话总结该页核心信息）
- 过渡动画统一用"淡入"（Fade），不使用花哨切换效果

P03 研究背景 · 目标 · 技术路线
背景关键词：政策导向（文旅融合"十四五"战略）、技术驱动（LLM+知识图谱成熟）、区域禀赋（90项非遗/80处文物/12个名村）、现实矛盾（文化沉淀 vs 旅游市场化衔接错位）
核心问题：南海区文化遗产与旅游产品之间存在怎样的对应、错位和缺失？如何量化？
五项目标：①多源数据库 ②双谱系模型 ③知识图谱 ④空间分析 ⑤方案设计
完成状态：前四项已完成，方案设计进行中
技术路线：典籍PDF→RapidOCR→语料库→千问LLM抽取→Neo4j图谱→耦合/空间分析；多源POI+评论数据→清洗匹配→体验度评估

P04 技术全流程架构
①数据采集层：典籍PDF(36本)用RapidOCR·12线程并行→53篇541万字；高德API+百度Place+佛山Shapefile→13,113条POI；高德/携程/去哪儿/马蜂窝→16,391条评论
②数据处理层：prepare_corpus.py编号索引统一格式；poi_cleaner.py去重融合11类分类+llm_poi_clean.py(Ollama)纠正类别；评论五段式匹配POI(rapidfuzz)
③知识抽取层：千问API(qwen-3.5-plus)多线程并发·断点续跑；实体抽取(AI分类6大类28小类+官方分类8大类)→8,048实体；关系抽取(9大关系组·开放式谓词·每条附证据)→19,382关系
④知识存储层：Neo4j图数据库·节点按AI小类(A1-F3)分标签·频次分档配色；关系按relation_group分类型·附证据属性；Cypher编程查询·路径分析·子图导出
⑤分析应用层：图谱NER提及+非遗名录+POI库→非遗耦合分析(四象限+协调度D值)；POI+非遗坐标→空间格局分析(KDE+DBSCAN)

P05 典籍OCR与语料库构建
OCR工具：RapidOCR（ONNX Runtime），多线程并行
处理对象：看典古籍458页→375,453字；31本南海文史PDF→约176万字；22份开题阶段典籍
代表性语料：佛山市志115万字、西樵山度假区志44万字、南海县志(OCR)37万字、文化艺术志24万字、历史人物录21万字
最终产出：prepare_corpus.py统一编号→53个编号语料文件·541万字·data/corpus/

P06 多源POI数据体系
三源融合：高德API 1,353条 + 佛山Shapefile 12,906条 + 百度Place API补充
融合清洗：poi_cleaner.py去重·坐标统一·11类自动分类→poi_cleaned.json 13,113条
LLM辅助清洗：llm_poi_clean.py用Ollama(qwen3:8b)多线程逐条纠正类别·标记文旅相关→poi_llm_cleaned.csv
文化锚点关联：165条政府普查级文化载体，500m半径关联POI，用于文化深度维度计算

P07 评论采集与POI匹配
采集平台：高德+携程+去哪儿+马蜂窝，合计16,391条评论
五段式匹配算法（命中即停）：①精确匹配(100分)→②核心名匹配去后缀(97分)→③别名括号匹配(95分)→④双向包含匹配排除泛化词(按比例)→⑤模糊匹配rapidfuzz≥72分(按得分)
匹配结果：3,073唯一景点名中403个匹配到南海POI(13.1%)；未匹配2,670个多为佛山其他四区景点
过渡：至此三大数据源（典籍语料·POI库·评论库）全部就绪，接下来对典籍语料进行LLM知识抽取

P08 LLM双标签知识抽取
模型：阿里千问qwen-3.5-plus（DashScope API），多线程(最高20线程)并发·断点续跑
体系一 AI研究分类（三层六大类28小类）：文化本体层(A非遗6小类+B物质文化6小类)→传承承载层(C传承主体4小类+D文化空间4小类)→认知支撑层(E文献记忆5小类+F历史时序3小类)
体系二 官方国标分类（8大类）：非物质文化遗产·不可移动文物·可移动文物·名城名镇名村·自然保护地·公共文化资源·旅游资源·非遗传承主体
双标注示例：醒狮→AI:A1表演艺术类非遗 + 官方:非物质文化遗产/传统舞蹈
抽取流程：语料分chunk(800字)→逐chunk提取→OpenCC繁简转换→AI+官方双校验→置信度过滤→合并去重
产出：8,048个去重实体

P09 九类语义关系体系
九大关系组：空间关联(位于/坐落于)·传承延续(师承/传承/演变为)·营建创造(创建/修建/捐建)·文献记载(记载/收录/载有)·时序归属(始建于/形成于)·从属分类(属于/下辖/又名)·文化表征(象征/承载)·社群组织(祭祀/主持/举办)·人物关联(出生于/创立/著述)
质量控制：方向校验(主谓宾通顺)·禁用空泛词黑名单·每条关系附原文证据(≤50字)·谓词自动归类为关系组·llm_relation_compliance.py合规审核
产出：19,382条语义关系，覆盖9大关系组

P10 Neo4j知识图谱
构建流程：neo4j_full_build.py读取merged_entities/relations→清库→创建约束索引→批量导入节点(Entity)→按AI小类添加标签(A1-F3)→按relation_group导入关系→移除Entity标签让Browser按小类分色→生成GRASS样式文件
节点属性：name·ai_label/ai_type·official_label/official_type·description·confidence/mentions·color/freq_rank/viz_diameter
配色方案：按AI小类频次降序6档（红→蓝→橙→紫→青→绿），高频类型节点更大更粗
查询示例：MATCH (p:C1)-[r]->(x) WHERE p.name='康有为' RETURN p,r,x；MATCH (n)-[r:人物关联]->(m) RETURN n,r,m
规模：8,048节点 + 19,382关系 · 28种节点标签 · 9种关系类型
过渡：图谱将典籍知识结构化存储，其中NER实体提及频次将输入耦合分析的文化资源度C计算

P11 非遗文旅耦合分析
7镇街；POI优先`poi_llm_cleaned.csv`（有效点约1.35万）；非遗落点26项(`nanhai_nonheritage.json`)；文化强度C含图谱实体提及+（有数据时）评论汇总`review_summary_merged.csv`。对齐四类：实体对应·文化承载·空间共存·主题关联。四象限：16 / 9 / 14 / 6 → `output/tables/coupling_summary.json`。
D 概览（降序）：桂城0.88极高、西樵~0.69高、大沥~0.66高、里水~0.65高、狮山~0.63高、丹灶~0.44中、九江~0.40低。

P12 空间格局分析
KDE(40×40·3km·Haversine)+DBSCAN(ε=3km)；POI源与P11一致。POI热区：桂城—大沥—狮山；非遗热区：西樵—九江—丹灶；两带错位。九江：非遗子集5项 vs POI 259（七镇合计13512、约1.92%），文化富集—旅游薄弱典型。

P13 核心发现与优化建议
（数字口径：`coupling_summary.json`，POI=LLM表+评论参与C。）
发现：①16对强耦合以基地/馆所为主 ②错位9·缺失A14·缺失B6 ③桂城协调最高、九江最低 ④空间热力错位（同P12）。
建议：非遗体验化；现代公园植入非遗展演；西樵书院/九江美食/古村连片线路（摘要见`coupling_summary.json`的 recommendations）。

P14 后续计划
4月上旬：知识图谱深化（图谱补全·子图分析·文旅关联挖掘）
4月中旬：文旅融合提升方案设计（基于耦合分析与图谱结果，设计2-3个方案）
4月下旬-5月上旬：论文撰写（整合全部分析结果）
5月中旬：查重、降重与论文修改定稿
5月下旬：答辩、答辩材料与归档收尾

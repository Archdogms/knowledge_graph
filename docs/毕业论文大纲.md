### **本科毕业设计论文大纲：基于大数据的佛山市南海区旅游景区文旅融合潜力研究**

**（注：本大纲依据开题报告、中期答辩内容及项目实际工作整理；中期后题目已调整为突出“旅游景区”与“文旅融合潜力”，并补充文献综述章与“耦合桥梁”表述。）**

---

#### **摘要**
简要概述整个研究。首先点明研究背景——在国家大力推动文旅融合和文化数字化的背景下，佛山市南海区虽拥有丰富的文化遗产（如 90 余项非遗），但在旅游开发中存在“文化沉淀”与“市场产品”衔接不畅的问题。接着说明本文的研究思路：通过构建“文化谱系”（基于典籍文献）与“景点谱系”（基于 POI 和评论数据），对两者进行对比，**从问题诊断走向潜力识别**。然后介绍核心工作：利用大语言模型从约 541 万字的典籍语料中抽取实体与关系，构建了包含 8000+ 节点的知识图谱；以 **91 项非遗名录** 作为**文化—旅游耦合桥梁**的主操作化载体，对文化资源与旅游载体进行匹配，识别耦合、错位与缺失，并讨论物质遗产、风景名胜区等品牌载体在同一逻辑下的**扩展可能**；结合空间分析方法，揭示文旅要素在地理分布上的格局与**潜力空间**。最后总结主要发现与**释放文旅融合潜力的对策**。

**关键词**：文旅融合；潜力；知识图谱；大语言模型；POI；非物质文化遗产；南海区

---

#### **第一章 绪论**

*   **1.1 研究背景与意义**
    *   **背景**：阐述国家及地方关于“以文塑旅、以旅彰文”的政策导向；介绍佛山市南海区丰富的文化资源禀赋（非遗、文物、古村落等）及其在**旅游景区**开发中面临的现实挑战——文化内涵未能有效转化为游客可体验的产品。
    *   **意义**：
        *   **实践意义**：为南海区乃至同类地区的文旅资源梳理、产品优化和规划决策提供基于数据的**潜力方向**与可操作路径。
        *   **方法意义**：探索将大语言模型、知识图谱与多源地理数据相结合，用于**区域文旅融合潜力**研究的技术流程。

*   **1.2 研究目标与内容**
    *   **目标**：构建一个分析框架，通过量化对比“文化记忆”与“旅游供给”，**识别南海区文旅融合的现状问题、潜力区域与潜力项目**。
    *   **内容**：
        1.  整理并处理南海区相关的多元大数据（典籍、POI、评论、非遗名录、**政府普查文化载体**等）。
        2.  构建基于典籍的文化知识体系（知识图谱）。
        3.  刻画基于市场的旅游产品体系。
        4.  设计并执行耦合分析，识别对应、错位与缺失，并**评估融合潜力**。
        5.  进行空间格局分析，从地理维度验证结论并**识别潜力空间格局**。
        6.  提出**有利于潜力释放**的优化建议。

*   **1.3 技术路线与论文结构**
    *   **技术路线**：`数据采集（OCR/爬虫/API）` → `数据清洗与结构化` → `知识图谱构建（实体/关系抽取）` → `双谱系耦合分析` → `空间分析` → `潜力研判与方案输出`。
    *   **论文结构**：第二章为文献综述与述评；第三章为研究区域与数据；第四章为知识图谱；第五章为旅游产品与耦合分析；第六章为空间格局；第七章为结论与建议。

#### **第三章 研究区域与数据基础**

*   **3.1 研究区域概况**
    *   简要介绍佛山市南海区的地理位置、行政区划。
    *   重点概述其文旅资源家底，如非遗项目数量与级别、代表性文物古迹、历史文化名村等。

*   **3.2 数据来源与处理**
    *   **典籍文献数据**：说明数据来源（如《南海县志》、《南海文史资料》等），介绍使用 RapidOCR 工具进行文本识别的过程，最终形成约 541 万字的标准化语料库。
    *   **旅游 POI 数据**：说明通过高德、百度等 API 及公开 Shapefile 获取了超过 1.3 万个兴趣点，并经过了去重、坐标统一和分类清洗（中期汇报中已说明三源融合及本地大模型辅助类别纠正等）。
    *   **用户评论数据**：说明从携程、马蜂窝等平台采集了约 1.6 万条评论，并通过“五段式匹配算法”将其精准关联到对应的 POI 上。
    *   **非遗名录数据**：列出作为**耦合桥梁**主操作化对象的 91 项南海区非物质文化遗产名录。
    *   **政府普查文化载体数据**（中期进展）：说明已纳入的**文化载体普查条目**（如中期材料中的 165 条）及其与 POI 的关联思路，用于辅助理解文化资源的空间锚定。

#### **第四章 文化知识体系构建：知识图谱的实现**

*   **4.1 实体与关系的定义**
    *   介绍为本研究专门设计的分类体系（可简述为六大类：非遗、物质遗产、人物、空间、文献、时序），并说明为何采用这种结构。
    *   介绍定义的九大关系类型（如“空间关联”、“传承延续”、“营建创造”等），强调关系抽取的开放性与证据保留原则。

*   **4.2 基于大语言模型的抽取过程**
    *   说明选用的模型（如 qwen-3.5-plus）及其理由。
    *   描述具体的抽取流程：将语料分块输入模型，进行实体和关系的识别，并采用双标签策略（研究分类+官方分类）对实体进行标注。
    *   介绍质量控制措施，如方向校验、禁用空泛词、保留原文证据等。

*   **4.3 Neo4j 图数据库的构建与可视化**
    *   说明如何将抽取结果批量导入 Neo4j 数据库。
    *   展示最终知识图谱的规模（8,048 个节点，19,382 条关系）。
    *   通过截图展示图谱的可视化效果，如全貌、康有为或黄飞鸿的人物关系子图等。

#### **第五章 旅游产品体系刻画与耦合分析**

*   **5.1 旅游产品体系的结构**
    *   基于清洗后的 POI 数据，简要分析南海区旅游产品的类型构成和空间分布概览（与**旅游景区**供给侧对应）。

*   **5.2 耦合分析方法：文化—旅游耦合桥梁（以非遗名录为主）**
    *   **核心思路**：耦合分析通过一套独立的、可复核的对照规则实现；**桥梁层**在概念上可涵盖非遗、物质遗产、风景名胜区等**可定位、可品牌化的文化载体**；本研究**操作化实现**以 91 项非遗名录为主，以利于与图谱实体、POI 名称匹配。
    *   **匹配规则**：以非遗名录为桥梁，向左匹配知识图谱中的相关实体（衡量文化记忆深度），向右匹配 POI 名称（衡量空间载体覆盖）。详细介绍名称清洗规则（如“狮舞（广东醒狮）”简化为“狮舞、醒狮”）。
    *   **与“中间件”一词**：正文采用“耦合桥梁”“衔接载体”等表述，避免软件工程语境下的“中间件”歧义。

*   **5.3 耦合分析与潜力解读**
    *   **四象限结果**：双向耦合、仅文化侧、仅 POI 侧、无匹配等，并阐释各象限对应的**潜力类型**（如高文化记忆—低载体即高转化潜力）。
    *   **典型案例分析**：
        *   **按级别**：指出市级非遗项目存在明显的“中间断层”，耦合率极低，**潜力释放**需政策与空间载体配合。
        *   **按镇街**：对比西樵镇（文旅融合较深）与九江镇（文化富集但旅游洼地）的差异，服务**差异化潜力策略**。

#### **第六章 文旅要素的空间格局分析**

*   **6.1 分析方法**
    *   简述采用的技术方法：核密度估计（KDE）用于识别热点，DBSCAN 用于发现集聚区。

*   **6.2 空间分析结果与潜力格局**
    *   **热点错位**：展示 POI 热点与文化资源热点的空间错位，从地理维度支撑“东旅西文”等判断。
    *   **镇街对比**：通过图表量化各镇街的文化资源密度与旅游产品密度，**识别高潜力镇街或廊道**。

---

#### **第七章 结论与建议**

*   **7.1 主要研究结论**
    *   总结全文的核心发现：文化未转化、市级断层、空间错位等，并归纳**文旅融合潜力的主格局**。

*   **7.2 文旅融合潜力释放与提升建议**（结合风景园林专业视角）
    *   针对高文化记忆、低载体的项目，提出传习所、活态展示等**潜力转化**措施。
    *   针对“有形无魂”的景点，提出文化叙事与活动植入。
    *   针对空间错位，提出线路与片区**潜力培育**建议（如古村落廊道、九江美食非遗集群等）。

*   **7.3 研究不足与展望**
    *   **不足**：数据层面（如 OCR 识别误差、评论数据的时效性）、方法层面（耦合桥梁以非遗为主、物质遗产等扩展尚待深化）等。
    *   **展望**：引入更多动态数据，或利用图谱算法挖掘文化关联路径，服务文旅 IP 与**潜力项目**筛选。

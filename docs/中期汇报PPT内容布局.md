## 一、全局版式（正文页共用）

正文由 **`slide_frame`** 包裹：**顶栏**（#003366 + 左红条）→ **副标题条**（#E8F4FC + 左蓝条）→ **正文区** → **页脚**（左数据来源、中板块名、右页码）。装饰为右上淡圆、右下淡色块。

**正文组件**（见 `generate_svgs.py`）：

| 组件 | 说明 |
|------|------|
| **body_two_column** | 左 580×430（海军蓝竖条）+ 右 580×430（红竖条），栏内标题 + 多行要点 |
| **body_stats_row** | 横向 KPI：大数字 + 标签 + 小字（浅蓝圆角底） |
| **body_stats_plus_bullets** | **上**：`body_stats_row`（y≈138）**下**：项目符号列表（y≈348 起，行距约 28）— **本版新增，用于「一页讲透」** |
| **body_bullets** | 左蓝条 + 19px 正文，可调 `y0` / `gap` 以塞入 4～6 条 |
| **body_file_list** | 全宽路径行 ×N（Consolas 路径 + 说明） |
| **body_quad** | 2×2 四宫格（耦合统计） |
| **body_cards_3** | 三卡横排收束结论 |

配色：海军蓝 `#003366`、红 `#CC0000`、蓝 `#0066CC`、浅蓝底 `#E8F4FC`、面板 `#F5F7FA`。

**页面标题**：非遗中间件匹配方法

### 一句话点题

> 以 **91项非遗名录** 为中间件，向左匹配知识图谱实体（文献记忆），向右匹配POI（空间载体）。

### 三角匹配示意图

```
              ┌─────────────────────┐
              │   91项南海区非遗名录  │
              │  清洗名称→提取主体关键词│
              └─────────┬───────────┘
                        │
            ┌───────────┼───────────┐
            ↓                       ↓
     知识图谱实体                 文旅POI
      8,048个                   13,512条
   （典籍提及次数）           （场馆/设施/活动点）
            ↓                       ↓
       文化记忆密度             空间载体覆盖
```

**匹配规则**：\*name\* 包含匹配——非遗关键词出现在实体/POI名称中，或反之；实体侧统计所有匹配实体的 mentions 之和。

### 名称清洗示例

| 原始名称 | → 关键词 |
|----------|----------|
| 狮舞（广东醒狮） | 狮舞、醒狮 |
| 九江双蒸酒酿制技艺 | 双蒸酒 |
| 松塘村孔子诞 | 孔子诞 |
| 藤编（大沥） | 藤编 |
| 糕点制作技艺（九江煎堆制作技艺） | 煎堆、糕点 |

规则：去掉泛化地名（广东/佛山/南海/九江/松塘村等），保留文化主体。

**本页要点**：非遗名录是独立的中间件——不是图谱的一部分，而是连接「文献记忆」与「空间载体」的桥梁。

### 三条核心发现

**① 文化未转化是最突出矛盾**
48.4%的非遗在典籍中有记载但无POI。粤剧314次mentions、龙舟190+次、灰塑54次——文化记忆深厚却无体验载体。

**② 市级非遗存在「中间断层」**
国家/省级耦合率~35%，区级~15%，市级仅**3.8%**。龙舟说唱、灰塑、香云纱等市级项目有显著文献记载却几乎无载体。

**③ 九江文旅倒挂最严重**
13项非遗 vs 仅259个POI（占全区1.9%）。西樵镇则以5项双向耦合领跑，是文旅融合最深的镇街。

### 优化方向

| 方向 | 内容 |
|------|------|
| 转化高mentions项目 | 龙舟说唱→演出点；灰塑→展馆；粤曲→曲艺剧场 |
| 填补市级断层 | 香云纱→体验馆；大饼→工坊；鹤装狮头→手作 |
| 九江集群 | 双蒸酒+煎堆+鱼花+酱油→非遗体验街区 |

**本页要点**：西樵文旅融合最深，九江文旅倒挂最严重；市级非遗的3.8%耦合率是优先突破方向。
